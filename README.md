# MSPM0 Embedded Dino Game

An embedded Dino-style endless runner game developed in C for the Texas Instruments MSPM0G3507 LaunchPad.

## Overview

The player controls a dinosaur and must avoid obstacles while the game continuously moves forward. A slide potentiometer controls the game speed, while buttons are used to control the dinosaur.

The game includes animation, collision detection, scoring, sound effects, and English/Spanish language support.

## Features

- Jumping and crouching
- Multiple obstacles
- Sprite animation
- Collision detection
- Score and high-score tracking
- ADC-controlled game speed
- DAC-based sound effects
- Timer interrupts
- Randomized obstacles
- Moving background elements
- English and Spanish language support
- ST7735 LCD graphics

## Hardware

- MSPM0G3507 LaunchPad
- ST7735 LCD
- Slide potentiometer
- Push buttons
- Speaker
